# 메뉴 연결 (영웅입지전 데이터 모드)
빈 메뉴 표와 빈 메뉴 조건 파일만 든 모드입니다. 아무 항목도 바꾸지 않습니다.

## 언제 쓰나요?
NPC 대화 선택지를 넣는 모드 중 메뉴 조건 파일(ConversationCondition.json)이 없는 모드는, 게임 모드 목록에서 그 파일이 있는 모드보다 뒤에 있으면 선택지가 게임에 나오지 않습니다. 켜진 모드 중 그 파일이 있는 모드가 하나도 없어서 순서로 맞출 수 없을 때 씁니다. 순서로 맞출 수 있으면 이 모드는 필요 없습니다.

## 쓰는 법
1. 릴리스에서 `loh-menu-link-1.0.0.zip` 을 받아 모드매니저에 끌어다 놓거나, 압축을 풀어 게임 폴더 `MODs` 에 넣습니다.
2. 게임 모드 목록 맨 아래에 두고 켭니다.

## 왜 되나요?
게임은 메뉴 조건 파일이 있는 모드를 읽을 때 NPC 선택지를 다시 짭니다. 이 모드를 맨 끝에 두면 마지막에 한 번 더 짜게 되어, 앞의 모든 모드의 선택지가 들어갑니다(게임에서 직접 확인한 동작).
